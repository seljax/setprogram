🎙 Генерация голоса

Озвучивание текстов глубоким дикторским голосом на основе примера.
Выберите голос, введите текст и нажмите «Сгенерировать».

🔊 Активный движок: Gemini TTS + Yandex SpeechKit API готов
⬆ Открыть в полном окне ⬅ На главную
⚡ Для генерации новых текстов требуется Gemini API ключ. Бесплатный ключ можно получить в Google AI Studio. Альтернативно — Яндекс SpeechKit.
💡 Полная версия студии: npm run dev в папке voice_ai
