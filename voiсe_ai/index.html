Вариант 2: Запуск интерактивной студии (с нейросетью)

Чтобы запустить полный интерфейс студии с возможностью синтеза новых текстов:

  1. Откройте терминал (командную строку) в папке проекта
  2. Выполните: npm install
  3. Запустите сервер: npm run dev
  4. Откройте ссылку в браузере: http://localhost:3000
