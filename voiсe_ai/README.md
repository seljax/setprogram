# Voice Narrator Studio — Студия озвучивания текстов

Проект для озвучивания текстов глубоким мужским баритоном (голос Charon, точное соответствие присланному аудиопримеру).

---

## 🎧 Вариант 1: Быстрое открытие без установки программ
Если вам нужно просто прослушать готовую аудиозапись и просмотреть текст:
1. Найдите в папке файл **`player.html`**
2. Дважды кликните по нему — он откроется в любом браузере (Chrome, Safari, Edge, Яндекс и др.)
3. Вы можете слушать аудио, регулировать скорость (0.8x, 1.0x, 1.25x), перематывать и скачать файл **`narrated_sample.wav`**.

---

## 🚀 Вариант 2: Запуск интерактивной студии (с нейросетью)
Для изменения текста, генерации новых вариантов речи и выбора эмоциональных стилей:

### Требования
- Установленный [Node.js](https://nodejs.org/) (версия 18 или новее).

### Команды запуска
1. Откройте терминал (командную строку) в папке проекта.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Для генерации **новых** аудиозаписей через нейросеть укажите ваш API-ключ Gemini:
   - Создайте в папке проекта файл **`.env`** (рядом с `package.json`).
   - Добавьте в него строку:
     ```env
     GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
     ```
   *(Бесплатный ключ можно получить за 1 минуту в [Google AI Studio](https://aistudio.google.com/app/apikey)).*
4. Запустите приложение:
   ```bash
   npm run dev
   ```
5. Откройте в браузере:
   ```
   http://localhost:3000
   ```

---

## ❓ Почему файл `index.html` при двойном клике показывал белый экран?
Файл `index.html` в корне проекта — это исходный файл сборки Vite + React + TypeScript.
Браузеры по соображениям безопасности (политика CORS) **запрещают** загрузку ES-модулей и TypeScript напрямую через протокол `file:///` без запущенного локального веб-сервера.

Для автономного запуска без сервера используйте файл **`player.html`**!
