💡 Почему index.html показывал белый экран при двойном клике?

Файл index.html в корне проекта — это исходный файл React + Vite + TypeScript. Современные браузеры по соображениям безопасности (CORS) блокируют запуск скриптов при простом открытии через проводник (file://).

Как пользоваться проектом:

  1. Без установки программ: Просто открывайте этот файл player.html двойным кликом в любом браузере. Он автономный и уже содержит готовое аудио и плеер.
  2. Запуск полной интерактивной студии (с возможностью озвучивать новые тексты нейросетью):
    Откройте терминал в папке проекта:
    1) npm install
    2) Создайте файл .env со строкой: GEMINI_API_KEY=ваш_ключ
    3) npm run dev
    После этого откройте в браузере: http://localhost:3000.
